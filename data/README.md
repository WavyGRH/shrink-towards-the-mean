# Data

`school.mat` (Inner London Education Authority exam scores, 139 schools, 15,362 students) is the
MALSAR release of the School benchmark. It is distributed with MALSAR under the GPL-2.0, so it is
not included here. Fetch it, with a SHA-256 check, by running from the repository root:

```
python scripts/download_data.py
```

Source: https://github.com/jiayuzhou/MALSAR/blob/master/data/school.mat
SHA-256: `57fb3238fdd03a9aa17276e2ce18d9bbb5d128c3261e794fe6233b58b6909068`
